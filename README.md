# solo-docs


Beginner's Guide to the Project [for Mac Users]
This guide mentions all the steps that you need to take to complete the assigned tasks within the project. 

Note: for any installation via Self Service in department's Mac device skip the part where it asks you to paste the application file in 'Application' folder. This way, you can still use the application. 

1. Instal VS Code
Go to Self Service, Install "VS Code" (https://code.visualstudio.com), open the VS Code, then click the symbol of 'four squares' on your left bar. An interface will be opneded with a list of extensions. Use the 'Search' bar to search for these extensions: 'Markdown All in One' and 'Peacock'(with 4.5 rating). 

2. Instal GitHub
Go to Self Service, install 'GitHub Desktop' (https://desktop.github.com/). It will ask you to sign-in. Create a free account (https://github.com/join), if you don't have one already. Or sign-in using your existing account details. You will use this account to store your files for this course on GitHub repository. 

3. Creating a Repository on GitHub
Open VS Code, create a public repository so that eveyone can view it. create an 'index.html' names file in it and add the link to you repository. 

4. Stage, Commit, Push
in GitHub Desktop, review your the file your created (Stage), write a short description about what you chnaged (Commit), then click 'Push origin' to upload to GitHub. This will track your changes. 

5. Deploy with GitHub Pages
In your repository, go to 'Settings' then 'Pages', set the source to your main branch and save. See 'Get started with GitHub Pages' (https://docs.github.com/en/pages/getting-started-with-github-pages).

7. Write 'README.md' File
In the end, create 'README.md' file in VS Code for this project's instructions. You are reading this file now. It is the first thing your visitors will see, and it's where you define 'what a project is' and 'how to use it'. Save the file in VS Code. Now open GitHub Desktop then, 'write descriotion, commit, push' changes.
